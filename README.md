# Portfólio — Kelvin Lucas

Portfólio pessoal desenvolvido para apresentar minha trajetória
profissional em Infraestrutura de TI e Suporte N2, minhas habilidades
e meus projetos de desenvolvimento.

🔗 **[Acessar o portfólio](https://klaolp.github.io/)**

## Funcionalidades

- Apresentação profissional e seção Sobre mim.
- Habilidades em infraestrutura, desenvolvimento e suporte.
- Página de projetos com tecnologias e links dos repositórios.
- Links de contato pelo GitHub e LinkedIn.
- Layout responsivo e menu adaptado para celulares.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages para publicação

## Estrutura do projeto

```text
├── index.html          # Página inicial
├── projetos.html       # Página de projetos
├── css/
│   └── estilo.css      # Estilos e responsividade
├── js/
│   └── script.js       # Comportamento do menu
├── imagens/            # Foto, favicon e recursos visuais
└── README.md           # Documentação do projeto
```

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/klaolp/klaolp.github.io.git
   ```

2. Acesse a pasta:

   ```bash
   cd klaolp.github.io
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível abrir a pasta no Visual Studio Code e utilizar
a extensão Live Server.

O projeto não exige instalação de dependências nem etapa de compilação.
